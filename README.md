# 🎮 Projeto 1 – Super Mario Bros: O Filme

Este projeto é uma **landing page** desenvolvida com HTML e CSS, inspirada no universo do filme **Super Mario Bros – O Filme**. Seu objetivo é apresentar o enredo principal, personagens e um botão para assistir ao trailer oficial, proporcionando uma experiência visual simples e interativa para os fãs da franquia.

## 🧱 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da página
- **CSS3**: Estilização da interface
- **JavaScript (básico)**: Para interatividade mínima (botão de trailer)
- **GitHub Pages**: Hospedagem do site

## 📌 Funcionalidades

- Layout responsivo e visual moderno
- Apresentação do enredo do filme
- Imagem de destaque do Mario e logo oficial
- Botão que redireciona para o trailer do filme no YouTube

## 🎯 Objetivos do Projeto

- Praticar a estruturação de páginas com HTML e CSS
- Desenvolver uma landing page temática
- Aprender a hospedar um projeto estático usando o **GitHub Pages**
