# Projeto1

#Resumo
O Projeto1 é uma landing page estática sobre “O Filme Super Mario Bros”, com design clean, navegação simples e foco em divulgar o trailer e sinopse. Será ideal para quem busca praticar front-end básico (HTML/CSS/JS) e construir páginas de apresentação visual. É um ótimo exercício para aperfeiçoar estrutura de página, responsividade e UX.
